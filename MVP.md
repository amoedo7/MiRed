# MVP · MiRed

## Resultado mínimo
Explicar cómo está conectado el dispositivo: interfaces, IP local, gateway/DNS disponibles y conectividad básica, sin exponer identificadores innecesarios.

## Aceptación
- detecta interfaces relevantes;
- diferencia conectado/desconectado;
- pruebas de reachability tienen timeout;
- no interpreta una IP como “Internet confirmado”;
- JSON versionado;
- sin escaneo de terceros fuera del alcance local/autorizado.
